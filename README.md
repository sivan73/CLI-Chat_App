# 📌 Overview

The **CLI Chat Application** is a real-time communication tool built for interactive messaging through a **Command Line Interface (CLI)**.

Developed using **Java** and the **WebSocket protocol**, the application enables multiple users to connect and communicate seamlessly in real time.

The project follows a clean and structured architecture focused on:

* Maintainability
* Separation of concerns
* Scalability
* Simplicity

---

# ✨ Features

* ⚡ Real-time chat functionality using WebSockets
* 💻 Command Line Interface (CLI) for user interaction
* 👥 Multi-user communication support
* 🧩 Clean and maintainable architecture
* 📦 Lightweight and easy to set up
* 🔧 Maven-based project structure

# 🚀 Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/sivan73/CLICHATAPP.git
```

## 2️⃣ Navigate to the Project Directory

```bash
cd cli-chat-app
```

## 3️⃣ Build the Project

```bash
mvn clean install
```

---

# ▶️ Running the Application

Start the application using:

```bash
mvn exec:java
```

---

# 🔌 WebSocket Communication

The application uses the **Java-WebSocket** library to establish real-time bidirectional communication between connected users.

This enables:

* Instant message delivery
* Persistent client connections
* Efficient communication handling

---

# 📖 Usage

1. Start the server/application.
2. Open multiple CLI instances.
3. Connect users through WebSockets.
4. Begin chatting in real time.
